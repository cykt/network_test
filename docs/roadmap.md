# NetDoctor 5주 로드맵

## 1주차 — 설계와 실행 골격

- 측정 경계, 반복 정책, 통계와 결과 스키마 확정
- 설정 검증, CLI, 대시보드 와이어프레임, 테스트 구현
- 완료 조건: 실제 네트워크 요청 없이 계획·데모·화면이 실행됨

## 2주차 — 측정 엔진

- DNS, TCP, TLS 보조 지표, 분리된 TTFB, 다운로드 처리율, ping 구현
- 5~10회 오케스트레이션, 부분 실패와 타임아웃 처리
- 완료 조건: CLI가 실제 측정 결과와 원본 표본·요약 통계를 JSON으로 출력함

## 3주차 — 설명 가능한 분석

- 단일 지표 및 조합 규칙 구현
- 웹, 1080p/4K 스트리밍, 화상회의 적합도 평가
- 모든 판정에 관측 근거와 불확실성 문구 포함
- 완료 조건: 고정된 테스트 시나리오마다 기대 진단과 근거를 반환함

## 4주차 — 웹 대시보드 연결

- FastAPI 측정 API와 현재 와이어프레임 연결
- 진행 상태, 표본 차트, 오류·부분 성공 화면 구현
- 로컬 측정 기록과 이전 결과 비교
- 완료 조건: 브라우저에서 진단 시작부터 결과 설명까지 완료됨

## 5주차 — 환경별 검증과 발표

- 유선/Wi-Fi, 유휴/부하, 가까운/원거리 대상 비교
- 기준값 조정, Windows/macOS/Linux ping 차이와 ICMP 차단 대응
- README, 보고서, 구성도, 시연 시나리오 완성
- 완료 조건: 재현 가능한 실험 근거와 함께 최종 시연이 가능함
